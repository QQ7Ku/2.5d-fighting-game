操作说明

键盘 · 桌面

  • 1P　A / D 移动，W 跳跃，S 下蹲
  • 1P 攻击　J 轻 · K 中 · L 重
  • 1P　U 必杀 · I 投技 · 空格 防御
  • 2P　← → 移动，↑ 跳跃，↓ 下蹲
  • 2P 攻击　小键盘 4 / 5 / 6，7 必杀，8 投，9 防
  • 攻击键可同时用作必杀指令的最后一击

手机 · 横屏

  • 左侧虚拟摇杆：左右移动，上推跳跃，下按防御
  • 右侧六键：轻 / 中 / 重 / 必杀 / 投 / 防
  • 必杀：摇杆摇 ↓→ 后按「必杀」，或直接按「必杀」触发简版
  • 投技：贴身时按「投」
  • 支持多点触控，按钮大小与透明度可在设置中调

系统

  • 三局两胜，每局 99 秒
  • 重击、必杀、投技撞墙可破坏场景
  • 场景三级破坏：装饰碎裂 → 立柱断裂 → 地面塌陷
  • 破坏后会改变战斗空间，注意地形

浏览器

  • 桌面：Chrome / Edge 最新版（推荐），Firefox / Safari 基础可用
  • 移动：Android Chrome、iOS Safari 横屏
  • 手柄：Web Gamepad 标准映射（可选增强）
