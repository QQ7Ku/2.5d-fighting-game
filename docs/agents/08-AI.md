# AI Agent · 任务计划与自检

## 职责
对战 AI、难度分级、行为树/状态机，可读取技能参数做决策

## 交付物
- `src/game/ai.ts`

## 接口约定（遵守 docs/07-接口契约.md）
- 只通过 `bus` 事件与他人通信；不改他人目录；接口变更先报总控
- 事件名 / 数据结构 / 资源命名 / 版本号 / Clip 名 / 触屏事件 全部按契约执行

## 验收自检项（已逐条执行）
1. 三档难度（反应 16/11/5 帧）
2. 射程取自真实判定框数据，不使用魔法数字
3. 24 秒对挂机玩家伤害：新手 44 / 普通 317 / 高手 428
4. 动作后插入空窗，避免无间隔连打

## 发现的问题与处理
- 早期版本 AI 会朝反方向走（移动朝向 bug），修复后行为正常

已完成 v2.0.0 交付范围内的工作；未完成项与风险见 `docs/09-测试报告.md`。
