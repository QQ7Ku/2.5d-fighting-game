# UI/音效 Agent · 任务计划与自检

## 职责
血条、计时、连击提示、破坏提示、加载界面、手机触屏 UI、Web Audio 音效

## 交付物
- `src/ui/hud.ts`
- `src/ui/touch.ts`
- `src/ui/screens.ts`
- `src/core/audio.ts`
- `src/style.css`

## 接口约定（遵守 docs/07-接口契约.md）
- 只通过 `bus` 事件与他人通信；不改他人目录；接口变更先报总控
- 事件名 / 数据结构 / 资源命名 / 版本号 / Clip 名 / 触屏事件 全部按契约执行

## 验收自检项（已逐条执行）
1. 血条含伤害残影、气条满值高亮、计时最后 10 秒变红
2. 连击数 + 累计伤害提示
3. 触屏六键 + 摇杆，大小/透明度/布局可调，键位可重映射
4. 安全区适配（env(safe-area-inset-*)）与横屏提示
5. 20 种合成音效 + 庭院环境声，首次手势解锁

## 发现的问题与处理
- 触屏点击短于一帧会丢输入，已加 pendingPress 锁存
