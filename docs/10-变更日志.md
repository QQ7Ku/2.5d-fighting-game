### 修复（阻断）

- **起跳在防御分支之后**：`tryJump` 原来写在移动段，按住后退时防御分支每帧 `return`，跳跃永远执行不到

- **脚底穿地**：蹲姿 −0.071、蹲防 −0.045、落地 −0.051、蹲攻 −0.074、KO 中段 **−0.294**。
  数据侧把 `rootY` 重新标定（蹲 −0.12 → −0.05、蹲防 −0.24 → −0.195、落地 −0.10 → −0.05、
  蹲攻 −0.18 → −0.11、KO t=0.3 −0.30 → −0.10 / t=1 −0.62 → −0.56），并在 `CharacterRig.apply()`
  加脚底兜底：任何 Clip 只要脚掌低于地面就把整体抬起。**复测 23 个 Clip × 2 角色最低 −0.007。**

### 修复（严重）

- **头顶灯笼打不到**：`resolveHit` 的冲击点取判定框**底边**（跳起重击底边 1.6 米），而灯笼挂在 2.97 米，
  纵向窗口 `h/2 + 1.0 = 1.27` 永远够不着 → 改取**框中心**（2.1 米），跳起重击第一次能打碎灯笼
  （实测 1 次命中带连锁碎 3 个）；地面重击仍打不到（dy 1.97 > 1.27），层级关系保住。
- **触屏 0.7 档按键互相重叠**：尺寸取 `max(44px, …)`、偏移取 `scale ×`，缩放后间距反而小于尺寸，
  最小边距 −11.8px → `.touch-actions` 改 3×3 网格，间距由 `--cell/--gap` 决定。
  **复测 3 档 × 3 种横屏：最小边距 +6px，键宽 ≥46px，与摇杆/暂停键均不重叠。**
- **暂停键被网格布局挤出屏幕**：`.tbtn` 改 `position: relative` 后暂停键继承 relative → 显式改回 absolute。
- **摇杆推到底不产生方向按键**：模拟轴只写 `axisX`，不进 `held`，于是「按住后 = 防御」在触屏上不成立
  → `|x| > 0.6` 时补 `left/right` 到 `held`。
