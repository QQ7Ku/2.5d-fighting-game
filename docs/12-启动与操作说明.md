# 12 · 启动与操作说明

版本 v2.0.3 · 构建产物 `dist/`

## 1. 本地启动（三种任选）

```bash
# 方式一：Python（无需安装依赖）
cd dist && python3 -m http.server 4173
# 浏览器打开 http://localhost:4173/

# 方式二：Node（任意静态服务器）
npx serve dist -l 4173

# 方式三：从源码起开发服务器
npm install && npm run dev      # http://localhost:5173
npm run build                   # 重新生成 dist/
```

> ⚠️ 不要直接双击 `index.html`（`file://`）。ES Module 与纹理生成在部分浏览器下会被 CORS 拦截。
> 必须通过 http 静态服务器访问。

## 2. 桌面操作

### 1P（左侧 · 李宾）

| 功能 | 键位 |
|---|---|
| 移动 | `A` / `D` |
| 跳跃 | `W` |
| 下蹲 | `S` |
| 轻 / 中 / 重攻击 | `J` / `K` / `L` |
| 必杀 | `U` |
| 投技 | `I` |
| 防御 | `空格` |

### 2P（本地双人 · 右侧 · 筄山）

| 功能 | 键位 |
|---|---|
| 移动 / 跳 / 蹲 | `←` `→` / `↑` / `↓` |
| 轻 / 中 / 重 | 小键盘 `4` / `5` / `6` |
| 必杀 / 投 / 防 | 小键盘 `7` / `8` / `9` |

- 蹲下 + 攻击 = 下段（Low），需蹲防。
- 必杀指令：→↓↘（前下前）+ 必杀 = 前绕系；←↓↙ + 必杀 = 后绕系。
  不输入指令、直接按必杀键也能触发（保证可玩性），此时按住「下」触发后绕系。
- 投技需贴身（≤1.5m），可破防。
- `Esc` 暂停。
- 键位可在「设置 → 键盘映射」中点击后按新键重绑，存档在浏览器本地。

### 手柄（可选增强）

标准 Gamepad 映射：十字键/左摇杆移动，`X/Y/B` = 轻/中/重，`A` = 必杀，`RB` = 投，`LB/RT` = 防御。
插入后在控制台可见"手柄已连接"提示；未测试所有型号，不列入验收硬指标。

## 3. 手机操作（横屏）

1. 用手机浏览器打开地址，**旋转为横屏**；竖屏时会显示旋转提示。
2. 建议点击菜单「全屏」进入全屏，避免地址栏占用。
3. 左下虚拟摇杆：左右移动、上推跳跃、下按蹲防（摇杆可小幅倾斜做微调）。
4. 右下六键：`轻` `中` `重` `必杀` `投` `防`，按 3×3 网格排布（上排 `轻` `中`，中排最右 `重`，下排 `防` `必杀` `投`），
   键与键之间保底 6px 间距、单键不小于 46px，支持多点触控（可同时移动 + 出招）。
5. 按住「下」再按「必杀」= 后绕必杀（如震地印）；直接按「必杀」= 前绕必杀。
6. 屏幕下方中央的 `‖` 暂停（原在右上角，会压住 2P 血条与角色名）。
7. 「设置」内可调：按钮大小 70%–150%、透明度 25%–100%、布局（标准/紧凑/左手）、主音量。

**性能档位**：菜单可选「自动/高/中/低」。自动模式在持续低于 26fps 时逐级降档，
高于 54fps 且稳定时升档；低档关闭阴影、贴花、落叶与补光，碎片上限降到 100。

## 5. 验收自检路线（3 分钟）

1. 打开页面 → 进度条走完 → 菜单出现（应 <1s）。
2. 选「对战 AI · 普通」→ 开战 → 左右移动、跳跃、轻中重攻击各打一次。
3. 打到气条 ≥25 → 按必杀（看到特效与掉血）。
4. 把对手打到墙边重击 → 立柱碎裂、碎片飞溅。
5. 贴身按住「下」+ 必杀 → 地面塌陷、角色坠坑。
6. 打空一管血 → KO 演出 → 第二局 → 再 KO → 结算面板。
7. 手机再走一遍 2–6，确认全部可用。

## 7. 已知限制

- 无训练模式、无暂停菜单内的按键配置（配置在设置面板）。
- **移动端不支持「本地双人」**：触屏只驱动 1P（没有第二套摇杆与六键），菜单里该选项在触屏设备上置灰并提示。
- 跳跃顶点约 0.78 个身位、滞空 15 帧；按住上键只跳一次，需松开再按。
- 塌陷地形在**同一对局的下一回合**会被修复（`Arena.resetTerrain()`，BUG-002 已修复）。
- 摄像头/麦克风/定位权限一律不请求；无任何埋点与上报。
- 首次点击前无声音（浏览器自动播放策略），点击后自动解锁。
