## 4. 原创合规声明

1. **不模仿**：本作未使用、改写或影射任何现有商业格斗游戏的角色名、招式名、动作套路、
   UI 术语、场景或音效。招式名（缠丝劲、震地印、回澜棍、掷棍归巢、靠山摔、挑梁式等）
   与角色名（李宾、筄山）均为本项目自创，命名取自通用武术词汇而非任何作品专有名词。
2. **美术**：全部几何体由代码参数化生成，无扫描、无抓取、无第三方模型/贴图；
   场景为架空"霜庭"院落，不还原任何现实或虚构作品的特定建筑。
3. **音频**：全部由振荡器与噪声实时合成，未采样任何录音、影片或游戏音源。
4. **字体**：仅使用操作系统自带字体，未内嵌或分发字体文件。
5. **代码**：全部为本项目编写，除第 2 节列出的宽松许可依赖外无第三方代码。
6. **生成内容**：Skill JSON 由模型辅助生成并经人工审核，Schema 明确禁止生成受版权保护内容；
   程序化场景仅使用数学函数与配色表，无参考图输入。
