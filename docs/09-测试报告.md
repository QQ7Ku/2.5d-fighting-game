### 3.4 为什么认为真机能达标（替代证据）

| 证据 | 数据 | 含义 |
|---|---|---|
| draw call | 常态 79，破坏峰值 82（碎片已实例化，与片数无关） | 现代移动 GPU 常规承受 200–1000+，桌面 GPU 数千 |
| 三角面 | 5.6k（破坏峰值 7.5k） | 相当于一个低模角色，远低于移动端 50k 预算 |
| 材质 | MeshToon（无贴图采样压力，2 张 256² 程序纹理） | 采样次数极低 |
| 阴影 | 单方向光 1024 贴图 | 一次 shadow pass |
| 后处理 | **无**（无 bloom/SSAO/FXAA） | 无全屏 pass |
| 纹理显存 | 4 张（floor/wall/panel/spark，均 256² 程序纹理） | <1 MB |

据此判断：真实 GPU 上桌面 60fps、移动 30fps 有较大余量，但**必须在真机复核**。

### 3.5 低帧率下的降级行为

- 逻辑帧固定 60Hz，单渲染帧最多补 **6** 步（`rawDt` 上限 0.1s，`0.1 / (1/60) = 6`）。
- 帧率 ≥ 10fps 时战斗逻辑基本实时（6 步 × 10 帧 = 60 逻辑帧/秒）；低于 10fps 时战斗节奏变慢（**BUG-006**，取舍而非崩溃）。
- 自动降档：连续 30 个采样均值 <26fps → 降一档（含首次 2s 稳定期）；>54fps 且稳定 → 升一档。
