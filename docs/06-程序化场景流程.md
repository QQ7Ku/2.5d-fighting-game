# 06 · 程序化场景描述流程

版本 v2.0.0 · 生成器 `scene/generator/generate.mjs`（`scene-gen/1.0.0`）
参数 `scene/params/shuangting.json` · 输出 `scene/output/decor.json` + `generation-record.json`

## 1. 生成范围的硬边界

| 内容 | 来源 | 理由 |
|---|---|---|
| 核心战斗区（13 × 7，战斗边界 ±5.6） | **手工** | 决定攻防距离与镜头构图 |
| 可站立地面分段（`floor-a/b/c`） | **手工** | 决定塌陷位置与地形改变范围 |
| 边界与碰撞体 | **手工** | 公平性 |
| 关键可破坏物（立柱、墙板、中庭地面） | **手工** | 破坏节奏与战斗影响 |
| 破坏触发点 / 塌陷区 | **手工** | 与必杀等级绑定 |
| 远景山脊轮廓 | 程序化 | 纯背景，无交互 |
| 院墙外树影（竹/松/灌木） | 程序化 | 装饰 |
| 地面苔痕/水渍贴花 | 程序化 | 纯视觉，无碰撞 |
| 灯笼分布（7 个） | 程序化 | 轻度破坏对象，位置随机但等级/耐久固定；z 必须落在后墙（−2.3）之前 |
| 碎片外观调色板 | 程序化 | 颜色随机，几何预设固定 |
| 落叶粒子种子 | 程序化 | 氛围 |

生成器源码里对 `manual` 段只有一处处理：`manual: { ...P.manual, source: 'hand-authored' }` —— **只读复制**。

## 3. 约束与自动校验

生成器在写入前执行 4 类断言，任一失败直接 `exit 1` 且不写文件：

1. **不进入核心战斗区**：`x ∈ (-6.6, 6.6)` 且 `z > -1.35` 的装饰一律违规；
2. **不遮挡判定框通道**：`y ∈ [0,3]`、`z > -1.35` 的通道必须净空（角色与判定框都在此通道内）；
3. **贴花可读性**：战斗地面上的贴花 `alpha < 0.45`；
4. **参数未越界**：数量、半径、层级均在 `params` 声明的范围内。

本次运行结果：`passed: true`，`violations: []`，4 项 checks 全部通过。

## 4. 可复现

- 随机源：`mulberry32(20261113)`，无 `Math.random()`、无时间、无网络。
- 输出指纹：`outputsHash = sha256(JSON.stringify(layers))` = `sha256:a70080e16228e1a6…`
- 参数指纹：`paramsHash = sha256(参数文件全文)`
- 复现命令：`node scene/generator/generate.mjs`（同一参数文件 → 同一 `outputsHash`；仅 `generatedAt` 变化）
- 验证方式：连续两次运行比对 `generation-record.json` 的 `outputsHash`（一致）。

## 6. 移动端降级

| 档位 | 装饰密度 | 具体 |
|---|---|---|
| 高 | 100% | 全部树影、贴花、落叶、灯笼、双点光源 |
| 中 | 70% | 隐藏后 30% 树影、保留贴花、保留落叶、关闭补光 |
| 低 | 42% | 隐藏大部分树影、关闭贴花与落叶、关闭补光、关闭阴影 |

降级只影响 `foliageGroup` / `patchGroup` / `leafPoints` / 灯光，
**不触碰** `manual` 段与碰撞、破坏逻辑 —— 与验收第 6 条一致。

## 8. 运行时零远程依赖（v2.0.7 口径修订 / v2.0.8 更新）

`decor.json` 在构建期被打进 bundle（`import decor from '../../scene/output/decor.json'`）。
自 v2.0.7 起，角色（`models/*.glb`）与场景件（`models/scene/*.glb`，v2.0.7 的 4 件 + v2.0.8 的 12 件 = 共 16 件）的 GLB **随包拷入 `dist/`，为同源本地文件**：
运行时**不发起任何外部网络请求**，也不调用在线生成服务；GLB 加载失败自动回退到程序化几何，游戏不崩。
「运行时零外部资产」的旧表述已修订为「零远程资产、随包本地 GLB」。若要新变体，改参数 + 换种子后重新构建。
**v2.0.8 授权边界变更（用户明确批准）**：修改唯一权威源 `scene/params/shuangting.json` 的 `manual.keyDestroyables`（新增 6 件 spec）并只改视觉参数 `palette` / `fogDensity` / `lighting`（夜色冷蓝 + 暖灯冷月光比），随后跑 `node scene/generator/generate.mjs` 重生成 `scene/output/decor.json`（**`decor.json` 是生成产物、不可手改**）；`layers` / `colliders` / `arena` / 既有 spec 与三级破坏逻辑不动。回归数字随之由 **11 件 / 126 片** 改为 **17 件 / 约 170 片**（< capMax 200），`docs/04` §9 与 `docs/09` §3.2 已回填。口径仍为「零远程资产、随包本地 GLB」。
