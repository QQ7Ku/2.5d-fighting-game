## 0. 开工流程（新会话必读，按顺序）

1. **先读本 README**（你正在看）—— 掌握项目身份、当前状态、线上/GitHub 入口。
2. **读 `交接单.md`** —— 最新一盒的七要素（目标/所做/输入/交给下一步/检查/未解决/变更记录），这是接手的**第一手状态**。
3. **读 `总目录.md`** —— 文档索引 + 版本进度总览。
4. **读 `项目日志.md`** —— 按时间线的历史决策，避免重复踩坑。
5. **读 `瓦上霜-迁移说明.md`** —— 换环境接手指南（线上链接、门禁脚本、密钥注入方式、未决事项）。

> ⚠️ **盒式工作流（用户强制）**：每盒只读当前文件夹 + 上一份《交接单.md》，完成必须输出《交接单.md》七要素；不顺手改别的盒；发现流程问题先提醒用户更新《项目日志.md》。用户语言表达偏弱，接任务先给可用产出 + 显式假设，再用结构化选项确认方向。

## 1. 项目身份

- **名称**：《瓦上霜》—— 2.5D 横版格斗游戏，山门古刹霜夜题材。
- **技术栈**：Three.js + TypeScript + Vite；场景由 `scene/` 生成器 + 低模 GLB（Three.js 渲染）构成。
- **当前版本**：v2.5.0（2026-11-21，第二张地图「竹海古径」+ 场景切换）。
- **线上状态**：线上仍为 v2.4.9；v2.5.0 源码已推 GitHub，**尚未发布线上**。分享链接见 §2（凭据链接，勿公开转发）。
- **GitHub 仓库**：`https://github.com/QQ7Ku/2.5d-fighting-game`（私有，默认分支 `main`，`master` 同源）。
- **源码包**：`瓦上霜-源码-v2.4.9-20261116.zip`（1.1G，224 文件；**不在本仓库**——超 GitHub 单文件 100MB 限制，已由 `.gitignore` 排除）。
